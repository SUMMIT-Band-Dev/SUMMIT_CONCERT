# SUMMIT 관리자 페이지 확장·개편 PRD (work05)

## 🎯 핵심 정보

**목적**: 공개 사이트에 하드코딩된 공연 정보(포스터, 제목, 장소, 날짜, 타임 테이블, 티켓, 유의사항, 예매 링크)를 어드민에서 한 곳만 고치면 모든 공개 페이지에 반영되게 하고, 유튜브 연결 관리를 "확인 → 수정 → URL 입력" 하나의 흐름으로 단순화한다
**사용자**: 매 공연마다 사이트 정보를 갱신해야 하는 SUMMIT 밴드 임원진(비개발자 콘텐츠 관리 담당자)

> 이전 어드민 PRD(`prd-admin.md`)의 F001~F010은 구현·배포 완료 상태로 그대로 유지한다. 이 문서는 신규·변경 기능(F014~)을 정의하고, 기존 기능은 기존 ID로만 참조한다.
> **폐기·대체되는 기존 기능**: F011(유튜브 배치 추천 검색)·F012(유튜브 추천 리뷰 — 승인/반려, 리뷰 대기/승인됨/반려됨 탭, 반려 사유, 재검토 대기열)는 **제거**한다. F013(유튜브 URL 수동 수정)은 F025로 **흡수·대체**한다.

## 🚶 사용자 여정

```
1. 로그인 페이지 (기존 F001)
   ↓ 아이디/비밀번호 입력 → 로그인 버튼

   [인증 성공] → 팀 관리 페이지 (기존 유지)
   [인증 실패] → 로그인 페이지 유지 + 에러 표시
   ↓

2. 상단 메뉴에서 수정할 대상 선택 (사용자 선택 분기점)

   [공연 제목·날짜·포스터를 바꿀 때]   → 공연 기본 정보 페이지
   [공연장이 바뀌었을 때]              → 공연장 정보 페이지
   [타임 테이블·예매 링크를 바꿀 때]   → 일차별 공연 페이지
   [티켓 이미지·요금 안내를 바꿀 때]   → 티켓 안내 관리 페이지
   [관람 유의사항을 바꿀 때]           → 관람 유의사항 관리 페이지
   [팀·곡을 바꿀 때]                   → 팀 관리 페이지 / 곡 관리 페이지 (기존 유지)
   [곡의 유튜브 영상을 바꿀 때]        → 유튜브 연결 관리 페이지
   ↓

3. 각 관리 페이지에서 입력/이미지 업로드 → 저장 버튼

   [검증 통과] → 저장 완료 표시 → 공개 사이트에 반영 (F026)
   [검증 실패] → 해당 입력 칸에 에러 표시, 페이지 유지
   ↓

4. [완료] → "공개 페이지에서 확인" 링크로 결과 확인, 또는 상단 메뉴로 다른 항목 수정
```

- 공연장 변경 흐름: 공연장 정보 페이지에서 주소 입력 → **위치 찾기**(주소로 좌표 자동 검색) → 지도 미리보기에서 마커 클릭·드래그로 위치 보정 → 네이버 지도 장소 링크 붙여넣기 → 저장 → Home 장소 문구, Ticket Info 장소, Contact Us 주소·지도·네이버 지도 링크, Stage Info 링크가 **한 번에** 바뀜
- 출연진 흐름: 일차별 공연 페이지에서 팀 관리 데이터로 만든 출연진 문구를 미리 확인 → 표기 조정이 필요하면 **직접 수정** → 저장 (언제든 **자동으로 되돌리기** 가능)
- 유튜브 흐름: 유튜브 연결 관리 페이지에서 곡별 연결 현황 확인 → **수정하기** → URL 입력 → 저장 (형식 오류 시 저장 불가 + 에러 표시)
- 미로그인 상태로 모든 관리 페이지 접근 시 로그인 페이지로 자동 리디렉션(기존 F002), 작업 중 세션 만료 시 현재 페이지 위 재로그인 대화상자(기존 동작 유지)

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F014** | 공연 기본 정보 수정 | 공연 **국문 제목·영문 제목**(각각 필수), 부제, 공연 시작일·종료일, 공연 시간을 입력·수정. Home 제목은 국문 제목, Ticket Info "공연 기본 정보"의 공연명은 영문 제목을 사용하고, 날짜·시간·부제는 두 페이지가 같은 값을 함께 사용 | 공연마다 바뀌는 가장 기본 정보이며 현재 페이지별로 표기가 갈라져 있음 | 공연 기본 정보 페이지 |
| **F015** | 메인 비주얼 이미지 교체 | 메인 배경(포스터) 이미지와 Home 타이틀 이미지(제목·부제 이미지)를 업로드해 교체. 타이틀은 **공연마다 이미지로 제작**되는 것을 전제로 하며, 이미지 대체 텍스트(alt)는 국문 제목·부제로 자동 지정. 포스터는 Home·Time Table·Ticket Info·Contact Us·관람 유의사항·예매하기·셋리스트 화면 배경에 공통 적용 | 포스터 1장 교체에 현재 6곳 이상 코드 수정이 필요 | 공연 기본 정보 페이지 |
| **F016** | 공연장 정보 수정 | 공연장 이름, 도로명 주소, 상세 주소(층 등) 입력·수정. Home 장소 문구, Ticket Info 장소, Contact Us 주소 텍스트, 지도 말풍선이 이 값을 공통 사용(단일 출처) | 이미 주소 불일치("마포구 양화로 100-10" vs "관악구 남부순환로 1937")가 발생함 | 공연장 정보 페이지 |
| **F017** | 지도 위치 지정 | **자동 검색 + 지도 보정 병행**: 입력한 주소로 좌표를 자동으로 찾아(네이버 Geocoding, 서버 호출) 지도 미리보기에 마커로 표시하고, 위치가 어긋나면 지도 클릭 또는 마커 드래그로 보정 후 저장. 자동 검색이 실패해도 지도에서 직접 지정해 저장 가능 | 비개발자가 위도/경도를 직접 입력할 수 없음 | 공연장 정보 페이지 |
| **F018** | 공연장 외부 링크 관리 | 공연장 홈페이지 링크(Stage Info 카드 연결 URL)와 네이버 지도 장소 링크(Contact Us "네이버 지도에서 보기")를 **직접 붙여넣어** 입력·수정(주소에서 자동 생성하지 않음), URL 형식 검사 | 공연장이 바뀌면 함께 바뀌어야 하는 링크 | 공연장 정보 페이지 |
| **F019** | 일차별 공연 정보 수정 | 일차별 라벨(예: Day 1), 날짜·시간 라벨(예: 6.25 (목) 18:00), 사전 예매 링크를 입력·수정. 예매하기 카드의 출연진 문구는 **기본적으로** 팀 관리(LineUp)의 해당 일차 팀명을 공연 순서대로 자동 표시하고, 줄바꿈·표기 조정이 필요하면 **직접 수정**(덮어쓰기)으로 바꿀 수 있음. 직접 수정 값이 있으면 그 값이 우선하며, **자동으로 되돌리기**로 자동 표시로 복귀 | 예매 링크·날짜는 공연마다 바뀌고, 출연진은 팀 데이터와 중복 관리하면 불일치 발생 — 자동 표시를 기본으로 두되 표기만 조정할 여지를 남김 | 일차별 공연 페이지 |
| **F020** | 타임 테이블 이미지 교체 | 일차별 타임 테이블 이미지 업로드·교체(현재 1일차/2일차 2장), 업로드 전 미리보기 | 타임 테이블은 매 공연 새로 제작되는 이미지 | 일차별 공연 페이지 |
| **F021** | 티켓 이미지 교체 | 티켓 앞면/뒷면 이미지 각각 업로드·교체, 티켓 설명 문구 수정 | 티켓 디자인은 매 공연 바뀜 | 티켓 안내 관리 페이지 |
| **F022** | 요금 안내 편집 | "입장 요금 안내", "여분 티켓 안내" 등 섹션 단위로 안내 항목을 추가·수정·삭제·순서 변경 | 요금·배부 정책이 공연마다 바뀜 | 티켓 안내 관리 페이지 |
| **F023** | 관람 유의사항 편집 | "관객 안전 안내", "주차 안내" 등 섹션 추가·이름 수정·삭제, 섹션별 항목 추가·수정·삭제·순서 변경 | 공연장이 바뀌면 안전·주차 안내 내용이 통째로 바뀜 | 관람 유의사항 관리 페이지 |
| **F024** | 곡별 영상 연결 현황 조회 | 팀별로 묶인 곡 목록에서 곡마다 현재 연결된 유튜브 URL(없으면 "미연결")을 표시, 팀 선택·미연결 곡만 보기 필터 | 어떤 셋리스트에 어떤 영상이 붙어 있는지 한눈에 확인 | 유튜브 연결 관리 페이지 |
| **F025** | 영상 URL 등록·수정 | 곡 행의 **수정하기** 버튼 → URL 입력 → 저장. 유튜브 URL 형식 검사, 빈 값으로 저장하면 연결 해제(공개 사이트는 기존대로 "곡명 가수" 검색 결과로 연결). 리뷰 상태 컬럼(`youtube_review_status`)은 읽거나 쓰지 않음. 기존 F013 대체 | 영상 연결 관리의 유일한 작업 흐름 | 유튜브 연결 관리 페이지 |

| **F026** | 공개 사이트 반영 | **저장 즉시 재검증(on-demand revalidation)**: 저장 성공 직후 해당 값을 쓰는 공개 페이지 캐시를 무효화해, 재배포 없이 다음 방문부터 새 값으로 표시. 저장 완료 후 "공개 페이지에서 확인" 링크 제공. 재검증 요청이 실패해도 저장은 유지하고 "저장됨 — 사이트 반영이 지연될 수 있음" 경고 표시(일정 주기 자동 갱신이 안전망) | "어드민에서 적으면 자동 반영"이 이번 작업의 목표 그 자체 | 공연 기본 정보 페이지, 공연장 정보 페이지, 일차별 공연 페이지, 티켓 안내 관리 페이지, 관람 유의사항 관리 페이지, 팀 관리 페이지(예매하기 출연진) |

> 이미지 업로드(F015, F020, F021)는 기존 카드뉴스 업로드(F007)의 업로드 → Storage 저장 → URL DB 반영 구조를 그대로 재사용한다.
